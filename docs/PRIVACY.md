# 花意加速器 隐私说明

更新日期：2026-11-18

公开可访问版本：<https://aka.doubaocdn.com/s/9EX5YNoJts>

花意加速器（包名 `com.swiftwind.accelerator`）是一个本地运行的 WireGuard 客户端。

## 我们收集什么

- 不收集账号、手机号、通讯录、位置、设备标识或使用行为数据。
- 不接入广告 SDK、统计 SDK 或第三方追踪服务。
- 不把节点配置、连接记录或流量统计上传到开发者服务器。

## 数据保存在哪里

- WireGuard 密钥、节点配置、订阅链接和当前选中节点只保存在本机应用的私有存储中。
- 应用崩溃时会在本机应用专属目录写入崩溃文本，用于排查问题；不会自动上传。
- 卸载应用会删除上述本地数据。

## 网络请求

- 点击「获取」时，应用会向 Cloudflare WARP 注册接口发送本机生成的 WireGuard 公钥，以获得免费 WARP 配置。Cloudflare 的隐私政策适用于该请求。
- 导入的订阅链接由用户提供；应用只按该链接拉取配置。
- 连接期间，流量经用户选择的 WireGuard 节点转发。节点运营方可能看到连接元数据，这是 VPN 服务的固有属性。

## 权限

- `INTERNET`：注册 WARP、拉取订阅、建立隧道。
- `ACCESS_NETWORK_STATE`：监听网络切换，用于断网恢复后自动重连。
- `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE`：连接期间保持 VPN 前台服务，降低 Android 在后台回收进程的概率。
- `POST_NOTIFICATIONS`：展示“VPN 已连接，网络保护中”的前台服务状态通知。拒绝该权限不影响连接，只是不显示该通知。
- VPN 授权由 Android 系统弹窗授予；应用不会自行绕过。

## 用户控制

- 可随时在应用内断开连接，或在系统设置中撤销 VPN 授权。
- 可删除节点、订阅和本地崩溃记录。
- 本应用不提供付费、账号或云端同步功能。
