## 完整说明

花意加速器是一个本地运行的 Android WireGuard 客户端。

- 内置 Cloudflare WARP 免费节点一键注册，根据注册结果生成多条出口线路
- 支持手动粘贴或批量导入 WireGuard `.conf` 配置
- 支持 HTTPS 订阅链接，自动去重
- 一键体检：真实建立隧道、检查握手与数据面，按质量排序线路
- 连接、断开、实时流量与连接时长
- 连接失败自动尝试备用 WARP 线路；切换失败自动恢复原节点
- Wi‑Fi / 移动网络切换后自动重连
- 连接期间使用前台服务保活，并展示状态通知
- 深色粉黑舞台风界面

应用不收集账号、位置、通讯录或使用行为数据；节点配置和连接统计只保存在本机。免费节点由 Cloudflare WARP 提供，线路质量会随运营商、地区和时间波动，不保证流媒体解锁或游戏低延迟。
