# Data safety / 数据安全表单填写稿

更新时间：2026-11-19

适用范围：Google Play「Data safety」表单。以下内容按当前 `1.1.0` 实现填写；如果后续接入统计、崩溃上报或账号体系，需要重新评估。

## 数据收集与共享

| 问题 | 填写 |
|---|---|
| 应用是否收集或共享任何必需用户数据类型？ | 否 |
| 是否收集位置？ | 否 |
| 是否收集个人信息（姓名、邮箱、电话、账号）？ | 否 |
| 是否收集通讯录、日历、短信？ | 否 |
| 是否收集照片或视频？ | 否 |
| 是否收集音频？ | 否 |
| 是否收集文件或文档？ | 否 |
| 是否收集应用活动或应用内搜索记录？ | 否 |
| 是否收集设备或其他 ID？ | 否 |
| 是否收集崩溃日志或诊断信息？ | 否（只写本机应用专属目录，不上传） |
| 是否与第三方共享数据？ | 否 |

## 网络安全

- 数据传输是否加密？是。WARP 注册、订阅拉取和隧道流量均使用 HTTPS / WireGuard。
- 是否提供数据删除方式？应用无账号体系；用户可在应用内删除节点，或卸载应用删除本地数据。
- 是否承诺遵守 Play Families 政策？应用不面向儿童，不含广告或用户生成内容。

## 第三方说明

- Cloudflare WARP：点击「获取」时，应用向 Cloudflare 注册接口发送本机生成的 WireGuard 公钥，以取得免费配置；Cloudflare 的隐私政策适用于该请求。
- 用户自行提供的订阅链接：应用只按链接拉取配置，不向开发者服务器转发。
- 应用不接入广告 SDK、统计 SDK、推送 SDK 或第三方追踪服务。

## 权限说明

| 权限 | 用途 |
|---|---|
| `INTERNET` | 注册 WARP、拉取订阅、建立隧道 |
| `ACCESS_NETWORK_STATE` | 监听 Wi‑Fi / 移动网络切换，用于自动重连 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE` | VPN 连接期间保活 |
| `POST_NOTIFICATIONS` | 展示 VPN 状态通知；拒绝不影响连接 |

## 审核备注

- 本应用的核心功能是用户主动发起的 WireGuard VPN 连接。
- 不采集用户流量内容，不插入广告，不做账号体系。
- 免费节点由第三方 Cloudflare WARP 提供；应用不承诺特定地区内容访问。
- 发布前需在干净设备上重新核对本表单与 release APK 的实际权限、SDK 和行为。
